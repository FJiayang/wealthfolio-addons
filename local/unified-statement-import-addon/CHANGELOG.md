# 版本记录

## [0.4.2] - 2026-11-07

- 修复微信 Excel 账单的日期序列值被误判为数值精度丢失，继续保留长数值订单号的精度校验。
- 补充 XLS/XLSX 日期解析回归和本地微信账单的模拟导入、重复导入验证。

## [0.4.1] - 2026-11-06

- 投资资金按基金公司与币种合并账户配置，同组流水只需选择和确认一次，修改账户后统一重新核对。
- 配置下方展示全部关联流水明细，保留每笔方向、金额、来源及独立资金转账；不同公司、币种仍分别配置。
- 只有日期的银行记录在关联明细中仅显示日期，不补充原文件未提供的时间。
- 补充普通账户等价付款方式去重及不同卡尾号隔离的界面回归验证。

## [0.4.0] - 2026-11-06

- 合并蚂蚁基金 PDF 与标准基金 CSV 导入，移除独立基金导入插件。
- 默认关闭投资识别；开启后记录银行卡与投资账户的资金转账及基金申购、赎回和分红再投资。
- 支持任意导入顺序、唯一可靠匹配、待关联记录人工确认、旧基金交易认领及取消关联。
- 复用宿主资产识别、表格编辑与主题，基金费用仅按最终收付金额计算一次。
- 确认统计、来源对账和转账配对复用宿主布局；统一单元格垂直对齐，内部复合查重编号不作为订单号展示。

## [0.3.0] - 2026-11-05

- 面向 Wealthfolio 3.12.0，新增民生、微众、汇丰香港、BMO、TD 渠道，完善微信退款及银行投资流水识别。
- 新增文字型和密码 PDF 本地解析、分页预览与来源定位，支持招商、民生、工商、中行和微众的参考格式。
- 银行与三方普通消费按同额、同币种、同账户和时间自动关联，保留双流水并将三方记账金额归零；支持历史记录及取消关联。
- 复制主项目导入展示组件并沿用宿主控件和主题；派生组件保留原许可，插件按 AGPL-3.0-only 发布。
- 真实样本目录不进入 Git 或安装包，新增本地真实流水的解析、模拟提交及重复导入测试。

## [0.2.1] - 2026-11-01

- 新增支付宝、微信、银行及记账平台 CSV、XLS、XLSX 账单的本地导入与多渠道识别。
- 支持多文件、工作表选择、账户推断与映射、原始文件预览、筛选后批量跳过和恢复。
- 支持账单疑点核对、手续费及真实转账关联，保留原始分类备注，保存后跳转收支页。
- 从活动页收支导入菜单打开插件，统一共享导入界面和多语言体验。
- 接入 PR 类型检查、单元测试和安装包验证，合并主干后独立发布 ZIP。
